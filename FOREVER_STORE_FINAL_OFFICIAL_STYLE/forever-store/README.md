# FOREVER Morocco Store — Official-inspired redesign

Next.js bilingual storefront (Arabic RTL + French) for an independent Forever Living Products distributor in Morocco.

## Included
- Official FOREVER logo loaded from the official Forever France asset URL
- Official-inspired yellow / green / warm cream / brown visual system
- Product-composition hero using multiple Forever product images
- Image-based category cards
- Since 1978 brand/story section
- Product grid with public 2026 prices
- Cart + COD checkout
- Existing `/api/orders` integration preserved
- Existing `ORDER_WEBHOOK_URL` n8n integration preserved
- Independent-distributor disclosure in hero/footer
- Responsive Arabic/French layout

## Deploy with Coolify
- Build Pack: Nixpacks
- Base Directory: `/forever-store` if this folder is stored under that path in the repository
- Static Site: OFF
- Keep the existing `ORDER_WEBHOOK_URL` environment variable

## Important
This is an independent distributor storefront and is not the corporate Forever Living Products website.
